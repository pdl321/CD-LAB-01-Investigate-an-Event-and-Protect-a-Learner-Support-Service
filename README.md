CD-LAB-01: Investigate an Event and Protect a Learner-Support Service

This Academy’s learner-support service is a proposed web application that helps learners get answers about programs, application deadlines, fees and academy policies. Learners submit questions through a web page. The service checks each request and looks up relevant information from approved academy sources.

For suitable questions, an external AI provider can draft a reply using relevant excerpts and a version of the question with personal details removed. Authorised staff verify the draft and decide whether to send it. They also handle questions that require human judgment and track follow-up tasks through a staff console.

The service records limited activity to help staff investigate errors or misuse. It is currently a design exercise using fictional learner data.
